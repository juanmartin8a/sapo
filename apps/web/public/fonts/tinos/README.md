# Tinos

Unmodified Regular, Bold, Italic, and Bold Italic WOFF2 files from
[Google Fonts' Tinos project](https://github.com/googlefonts/tinos/tree/3b4482a99b80ea5fc75f187b1be3120a3f5905b3/fonts/webfonts),
commit `3b4482a99b80ea5fc75f187b1be3120a3f5905b3`.

These are static faces at weights 400 and 700, self-hosted and declared in
`src/styles/base.css` for the website, translator, and PWA.

The full copyright notice and SIL Open Font License 1.1 are in `LICENSE.txt`.
The font files also retain the upstream copyright and license metadata.
