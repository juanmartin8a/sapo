# Tinos

Unmodified Regular (400) and Bold (700) TTF files from
[Google Fonts' Tinos project](https://github.com/googlefonts/tinos/tree/3b4482a99b80ea5fc75f187b1be3120a3f5905b3/fonts/ttf),
commit `3b4482a99b80ea5fc75f187b1be3120a3f5905b3`.

Loaded from bundled assets by `AppFontsProvider`. Use each face's explicit alias
from `constants/fonts.ts` so native platforms use the actual font weight.

The full copyright notice and SIL Open Font License 1.1 are in `LICENSE.txt`.
The font files also retain the upstream copyright and license metadata.
